# Обоснование выбора разделов проверочного листа

## Состав разделов

| Раздел | Включён | Основание - проблема или приоритет компании |
|---|---|---|
| I. Управление доступом | Да, расширен | Клиент видит в личном кабинете ПДн другого клиента; партнёр получает доступ к данным чужой УК; сотрудники работают под чужими учётными записями |
| II. Безопасность данных | Да, расширен | Нарушен контроль данных: несколько точек регистрации, потоки между продуктами не контролируются, со стороны систем обработки нет ограничений на доступ |
| III. Защита инфраструктуры | Да, сокращён | Из механизмов защиты периметра описан только firewall; развёртывание гибридное - собственный ЦОД, приватное облако, арендованные мощности |
| IV. Управление инцидентами | Да | Утечка у конкурента; инцидент с отображением чужих ПДн не был выявлен системой, о нём стало известно из жалоб клиентов |
| V. Специфические аспекты | Да, переработан | Мобильное приложение как канал доступа собственников; облачные ресурсы для доработки и тестирования |
| **VI. Безопасность внешних интеграций и API** | **Добавлен** | Вторая из двух глобальных проблем компании: API партнёров без единых политик и без контроля передаваемых данных |
| **VII. Соответствие законодательству** | **Добавлен** | Прямая потребность бизнеса: проверить соответствие требованиям законодательства РФ и предотвратить штрафы |
| **VIII. Организация процессов ИБ** | **Добавлен** | Специалист по ИБ один на компанию, процесс передачи ему решений и изменений нарушен |

## Добавленные разделы

| Раздел | Чего нет в базовом шаблоне |
|---|---|
| VI. Безопасность внешних интеграций и API | Шаблон проверяет защиту периметра и доступ пользователей, но не контракты API и не модель доступа партнёров: состав передаваемых полей, проверку принадлежности объекта, порядок допуска нового партнёра |
| VII. Соответствие законодательству | Законодательство упомянуто в шаблоне одним вопросом о политике классификации. Проверяются обязанности оператора по 152-ФЗ: уведомление Роскомнадзора, согласия, права субъекта, обезличивание, локализация хранения |
| VIII. Организация процессов ИБ | Шаблон проверяет наличие средств защиты, но не процесс: включённость ИБ в согласование изменений, владельцев данных, реестр интеграций, оценку рисков перед запуском |

## Изменённые разделы

| Раздел | Изменение |
|---|---|
| I. Управление доступом | Добавлены вопросы об изоляции арендаторов и проверке принадлежности объекта: шаблон проверяет роли и привилегии, но не сопоставление запрашиваемого объекта с правами пользователя |
| II. Безопасность данных | Добавлены вопросы о составе CDC-потоков и обезличивании в хранилище |
| III. Защита инфраструктуры | Убраны вопросы о рабочих станциях, антивирусе и сигнатурах: не связаны с заявленными проблемами. Усилены вопросы сегментации сети, добавлены вопросы по Kubernetes |
| V. Специфические аспекты | Сокращена физическая безопасность, расширены облачная инфраструктура и мобильные устройства |
