# Идентификация систем PropDevelopment

Системы из диаграммы контейнеров, сгруппированные по доменам. Для каждой указан характер
работы с точки зрения безопасности: обрабатываемые данные, точки входа, интеграции.

## Домен "Группа сервисов для клиентов"

| Система | Технология | Данные | Особенности с точки зрения безопасности |
|---|---|---|---|
| Витрина продаж | JavaScript, React | Каталог объектов, формы бронирования | Публичная точка входа из интернета через firewall. Собственной БД нет. Собирает ПДн и передаёт в четыре системы: client-crm-app, client-mart-app, client-mart-estate-app, client-tour-app |
| client-mart-app | Kotlin, Spring Boot | Онлайн-сделки, расширенные формы клиента | Обрабатывает наиболее чувствительные ПДн. Внешняя интеграция с госорганами через СМЭВ [SOAP], требует ЭП |
| client-mart-db | PostgreSQL | Объекты недвижимости, сделки | Прямой доступ [JDBC]. Источник CDC в хранилище |
| client-mart-estate-app | Kotlin, Spring Boot | Карточки объектов, цены, статусы | Публикует каталог объектов [Kafka] |
| client-mart-estate-db | PostgreSQL | Фонд недвижимости | Прямой доступ [JDBC]. Источник CDC в хранилище |
| client-tour-app | Kotlin, Spring Boot | Записи онлайн-туров, результаты осмотров | Медиа-данные с идентификацией клиента. Вызывается из client-crm-app |
| client-tour-db | PostgreSQL | Данные онлайн-туров | Прямой доступ [JDBC] |
| client-crm-app | Spring Boot, ElasticSearch, Dynamics CRM | Профили и карточки клиентов, ПДн | Точка регистрации клиента. Аутентифицирует менеджеров через Active Directory |
| crm-db | MSSQL | ПДн клиентов | Прямой доступ [JDBC]. Источник CDC в хранилище |
| auth-service-1 | Keycloak | Учётные данные, токены, сессии | Обслуживает и клиентов, и собственников - единая точка компрометации |
| auth-db-1 | PostgreSQL | Хеши паролей, сессии | Прямой доступ [JDBC] |

## Домен "Группа сервисов ЖКУ"

| Система | Технология | Данные | Особенности с точки зрения безопасности |
|---|---|---|---|
| Витрина сервисов для собственников | Mobile app (iOS, Android) | Сессии, локальный кеш ПДн | Публичная точка входа с мобильных устройств. Через неё пойдут новые сервисы "Умный дом" |
| tenant-core-app | Kotlin, Spring Boot | Начисления ЖКУ, платежи, заявки, ремонты, "Умный дом" | Интегрирован с внешними системами: API управляющих компаний, поставщики ресурсов ЖКХ, платёжная система. Мультиарендная модель: обслуживает несколько УК |
| tenant-core-db | PostgreSQL | Начисления, платежи, лицевые счета | Прямой доступ [JDBC]. Источник CDC в хранилище |
| CRM (ЖКУ) | Kotlin, Spring Boot | ПДн собственников, состав ЖК | Вторая точка регистрации пользователя, не согласованная с client-crm-app. Аутентификация менеджеров через Active Directory |
| crm-tenant-db | PostgreSQL | ПДн собственников | Прямой доступ [JDBC]. Источник CDC в хранилище |

## Домен "Дата"

| Система | Технология | Данные | Особенности с точки зрения безопасности |
|---|---|---|---|
| Хранилище данных | Greenplum | Сырые данные CDC со всех продуктовых БД | Концентрирует реплики ПДн всех систем. Ограничений на доступ к данным со стороны систем обработки нет |
| DWH Хранилище | S3 | Физическое хранение данных | Часть мощностей арендована у облачного провайдера |
| BI и отчётность | - | Аналитические витрины | Доступ аналитиков BI к данным, включающим ПДн |

## Общая инфраструктура

| Компонент | Особенности с точки зрения безопасности |
|---|---|
| Active Directory (прикладные системы) | Обслуживает бизнес-системы и системы обработки данных. Единая точка управления правами |
| Firewall | Единственный описанный механизм защиты периметра для внешних пользователей |
| Собственный ЦОД, приватное облако, арендованные мощности провайдера | Гибридная модель: часть продуктов и резервных копий вне собственного контура |
| Kubernetes | Среда развёртывания большинства бизнес-сервисов (по условию Task4) |

## Внешние системы

| Система | Протокол | Данные | Особенности с точки зрения безопасности |
|---|---|---|---|
| API управляющих компаний | REST | Данные ЖК, лицевые счета, начисления | Единых политик безопасности нет. Контракты содержат избыточные ПДн и не проверяют принадлежность объекта запрашивающей УК |
| Платёжная система | REST | Платежи по ЖКУ | Провайдер онлайн-платежей |
| Поставщики ресурсов ЖКХ | REST | Показания, начисления | Три отдельные интеграции |
| Государственные регистрационные органы | СМЭВ [SOAP] | Регистрационные действия по сделкам | Юридически значимый обмен, требует ЭП |
